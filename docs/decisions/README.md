# Architecture Decision Records (ADR)

PlanPing 프로젝트를 개발하며 마주한 기술적 고민과 의사결정 과정을 기록하는 디렉토리입니다.
단순히 '어떤 기술을 썼다'는 결과가 아니라, '왜 이 기술을 선택했는지(Why)'에 대한 논리적인 근거와 트레이드오프(Trade-off)를 남깁니다.

## 문서 작성 규칙
새로운 기술 스택을 도입하거나 중요한 아키텍처 결정을 내릴 때, 아래 4가지 항목을 포함하여 작성합니다.
* **배경 (Context):** 해당 의사결정이 필요해진 상황과 요구사항
* **대안 (Alternatives):** 고려했던 여러 기술이나 설계 방식들
* **결정 (Decision):** 최종적으로 채택한 방법
* **이유 (Reason):** 성능, 확장성, 학습 목적 등 해당 선택이 프로젝트에 가장 적합했던 구체적인 근거
