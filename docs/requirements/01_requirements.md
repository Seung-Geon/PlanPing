# PlanPing 요구사항 정의서

## 1. 프로젝트 개요
> **PlanPing**은 사용자가 목표를 세우고, 제때 알림을 받아 실천하며, 통계로 자신의 성장을 기록할 수 있도록 돕는 일상 플래너 서비스입니다.

## 2. 사용자 시나리오 (User Flow)
1. 사용자는 이메일과 비밀번호로 회원가입 및 로그인을 한다.
2. 오늘 할 일(계획)과 알림을 받을 시간을 설정한다.
3. 설정한 시간이 되면 서비스(또는 기기)로부터 알림을 받는다.
4. 계획을 실천한 후 완료(체크) 처리를 한다.
5. 주간/월간 달성률 통계를 확인하며 성취감을 얻는다.

## 3. 상세 요구사항 (기능 요구사항)

### 3.1 회원 (User)
| 요구사항 ID | 기능명 | 상세 설명 | 우선순위 |
| :--- | :--- | :--- | :---: |
| `REQ-U-01` | 회원가입 | 이메일, 닉네임, 비밀번호를 입력받아 회원을 생성한다. | 높음 |
| `REQ-U-02` | 로그인 | 이메일과 비밀번호로 인증하고 토큰을 발급한다. | 높음 |
| `REQ-U-03` | 회원탈퇴 | 회원 정보를 삭제한다. | 높음 |
| `REQ-U-04` | 정보 수정 | 회원 정보를 수정한다. | 중간 |

### 3.2 계획 (Plan)
| 요구사항 ID | 기능명 | 상세 설명 | 우선순위 |
| :--- | :--- | :--- | :---: |
| `REQ-P-01` | 계획 작성 | 제목, 내용, 목표 시간, 알림 설정 여부, 카테고리를 입력받아 저장한다. | 높음 |
| `REQ-P-02` | 계획 목록 조회 | 사용자의 특정 날짜(또는 전체) 계획 목록을 조회한다. | 높음 |
| `REQ-P-03` | 계획 수정/삭제 | 작성된 계획의 내용이나 시간을 수정하거나 삭제한다. | 보통 |
| `REQ-P-04` | 계획 완료 처리 | 진행 중인 계획의 상태를 '완료(DONE)'로 변경한다. | 높음 |
| `REQ-P-05` | 계획 회고 | 계획 완료 이후 해당 계획에 대한 회고를 작성할 수 있다. | 중간 | 

### 3.3 알림 (Notification)
| 요구사항 ID | 기능명 | 상세 설명 | 우선순위 |
| :--- | :--- | :--- | :---: |
| `REQ-N-01` | 리마인드 알림 | 계획에 설정된 시간이 되면 사용자에게 알림을 발송한다. | 보통 |

### 3.4 통계 (Stats)
| 요구사항 ID | 기능명 | 상세 설명 | 우선순위 |
| :--- | :--- | :--- | :---: |
| `REQ-S-01` | 일간/주간 통계 | 전체 계획 대비 완료된 계획의 비율(%)을 계산하여 제공한다. | 보통 |
