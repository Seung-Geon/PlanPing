# Database Design & Modeling
데이터베이스 모델링, ERD 설계, 스키마(DDL) 스크립트를 관리하는 디렉토리입니다.
백엔드 시스템의 핵심인 데이터 구조와 관계, 성능 최적화를 위한 인덱스 설계 등을 기록합니다.

## 문서 작성 규칙
* 데이터베이스 구조나 컬럼이 변경될 경우, 코드를 수정하기 전 ERD 문서를 먼저 업데이트합니다.
* 성능 최적화를 위해 복합 인덱스를 추가하거나 쿼리를 튜닝한 경우, 해당 배경과 튜닝 결과를 기록으로 남깁니다.
