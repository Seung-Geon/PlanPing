# PlanPing (플랜핑)

계획 작성, 실천 알림, 달성률 통계까지 한눈에 관리하는 스마트 일상 플래너입니다. 

## 기획 의도 및 학습 목표
- **스스로 고민하는 개발:** AI 코드 생성 도구에 대한 의존도를 최소화하고, Java와 Spring Boot의 동작 원리를 직접 부딪혀가며 깊이 있게 이해하는 것을 최우선 목표로 합니다.
- **성장 기록:** 개발 과정에서 마주치는 에러와 트러블슈팅 과정을 꼼꼼히 기록하여, 문제 해결 능력을 기르고자 합니다.
- **실용성:** 단순히 만드는 것에 그치지 않고, 실제로 나의 일상을 관리하는 데 사용할 수 있는 완성도 높은 서비스를 지향합니다.

## 기술 스택
- **Backend:** Java, Spring Boot, Spring Data JPA
- **Database:** MariaDB, Redis

## 주요 기능 (개발 예정)
1. **일정 관리:** 간단하고 직관적인 계획표 작성
2. **리마인드 알림:** 계획 시간에 맞춘 알림 발송 기능
3. **달성률 트래킹:** 실천 여부 체크 및 통계표 제공
